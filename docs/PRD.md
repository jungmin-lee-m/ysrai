## 1. 제품 개요

**의사랑 AI**는 의사랑 EMR과 연동되는 데스크톱 진료 보조 AI다. 진료 환자와 동기화되어 **과거 진료기록을 요약**하고, 진료 대화를 녹음·전사하여 **SOAP·진단·처방을 자동 생성**한다. 또한 일반 질문과 의사랑 데이터 질의에 응답하는 **대화** 기능을 제공한다.

> 제품 한 줄 정의: "환자 과거력은 자동으로 요약하고, 진료 기록은 음성으로 자동 작성한다."

## 3. 핵심 개념 — 두 개의 기능

제품은 **대화**와 **AI 진료** 두 기능으로 구성된다. 좌측 패널 상단 탭으로 전환하며, 진입 시(랜딩) 둘 중 하나를 선택한다.

| 기능 | 정의 | 의사랑 연동 |
|---|---|---|
| **AI 진료** | 진료 환자와 동기화하여 과거력 요약, 음성 진료 기록(STT→SOAP), 진단·처방 추천·전송을 제공 | 진료 환자 데이터 연동 |
| **대화** | 일반·개인 질문과 의사랑 데이터 질의에 응답(질문 성격 자동 판별) | 데이터 질의 시 연동 |

## 4. AI 진료

### 4.1 기능 구성과 핵심 기능
AI 진료는 다음 세 가지 기능으로 구성된다. 이 중 **과거 진료기록 요약**과 **음성 진료 기록(STT→SOAP)** 을 핵심 기능(Top 2)으로 정의하며, 두 기능 간 우선순위는 출시 후 사용 데이터를 통해 확정한다.

1. **과거 진료기록 요약** — 의사랑 진료 환자와 동기화되어, 환자 호출 전후 과거 진료 이력을 신속히 파악하도록 지원한다.
2. **음성 진료 기록 (STT → SOAP)** — 환자 호출과 동시에 녹음이 시작되어 진료 대화를 전사하고, 녹음 종료 시 SOAP를 자동 생성한다.
3. **진단·처방 추천 및 전송** — 환자의 과거 진단·처방 중 금일 진료 내용과 부합하는 항목을 재처방(리피트) 후보로 제시하며, SOAP와 함께 단일 동작(원클릭)으로 의사랑에 전송한다.

**기대 효과(세 기능 공통):** 과거력 조회·작성 및 차팅 부담을 줄여 진료기록 작성 시간을 단축하고 진료 업무 효율을 높인다.

### 4.2 표준 진료 플로우
```
환자 호출 ─▶ (자동) 녹음 시작 + 과거력 요약 표시
        ─▶ 진료 대화 STT 전사
        ─▶ 녹음 종료 ─▶ SOAP 자동 생성
        ─▶ 과거 진단/처방 기반 리피트 후보 제시
        ─▶ SOAP·진단·처방 원클릭 의사랑 전송
```

### 4.3 환자 목록 (의사랑 대기리스트 연동)
- 의사랑 대기리스트와 동기화된 환자 목록을 **진료 날짜 기준**으로 표시한다.
- 목록은 **대기 / 예약 / 완료** 세 섹션의 아코디언으로 구성한다.
- **날짜 기본값은 금일**이며, 달력에서 과거·미래 날짜로 이동할 수 있다.
- 선택한 날짜에 따라 **기본 확장 섹션**이 달라진다.

| 선택 날짜 | 기본 확장 섹션 | 목적 |
|---|---|---|
| 금일(기본) | **대기** | 금일 진료 대상 확인 |
| 과거 | **완료** | 지난 진료 환자 조회 |
| 미래 | **예약** | 예정 환자 확인 |

> 과거·미래 날짜에서의 환자 호출 등 액션 처리 방식은 추후 보완 예정이다.

- 환자 행 구성: 차트번호 · 이름 · 나이/성별 · (신환) · 상태. 완료 환자는 수납 상태(수납대기/수납완료)를 표시한다.
- 환자 행에 포인터를 올리면(호버) **호출하기** 액션이 노출된다.

### 4.4 좌측 패널
- **상단 탭**: 대화 / AI 진료
- **상단 녹음 상태바**(공통) — §6 참조
- **AI 진료 탭 본문**: 진료 날짜(달력) + 환자 목록(대기/예약/완료)
- **패널 접기/펴기**
  - 패널은 접을 수 있으며, **접은 상태에서도 녹음 상태(녹음 중/대기)를 좌측 레일에 표시**한다.
  - 접힌 레일에 포인터를 호버하면 **좌측 패널이 본문 위로(좌측에서) 오버레이로 슬라이드**되어 노출된다.
  - 이를 통해 좁은 화면 폭에서도 환자 목록 접근 및 호출을 지원한다.
- **반응형(컴팩트)**: 패널 폭을 줄이면 상태 뱃지 및 부가 정보가 축약된다(환자 이름은 유지).

### 4.5 중앙 진료 화면
현재 조회 중인 환자를 기준으로 다음을 표시한다.
- **환자 정보 헤더**: 차트번호 · 이름 · 나이/성별 · 보험 · 특기사항(접수메모)
- **녹음 상태바**(조회 중인 환자 기준) — §4.6 참조
- **과거 진료기록 요약** — 환자 진료 이력을 자동 분석한 위젯(약물·관찰·검사·시술·예방접종 등)
- **SOAP** — 녹음 완료 시 생성. 다시 생성 / 복사 / 의사랑 전송 액션 제공
- **진단·처방 추천** — 과거 차트 기반 리피트 후보로, 각 항목에 **출처 차트 날짜**를 표기하고 항목별 전송을 지원한다. 환자가 지정된 경우에만 표시한다(환자 미지정 진료에는 비노출).

### 4.6 녹음 세션 규칙
녹음은 **특정 환자에 귀속된 단일 세션**으로 동작하며, '조회 중인 환자'와 분리하여 관리한다.

| 상황 / 동작 | 처리 |
|---|---|
| 환자 호출 | 해당 환자로 녹음 자동 시작 |
| 녹음 중 다른 환자 **조회**(선택) 또는 다른 대화로 이동 | 녹음 **유지**(대상 환자 불변) |
| 녹음 상태바(좌측/중앙) 선택 | 녹음 중인 환자 진료 화면으로 복귀 |
| 상단 녹음 상태바에서 중지 | 녹음 종료 후 해당 환자 **SOAP 화면으로 전환** |
| 녹음 중 **다른 환자 호출** | **확인 모달** 노출 — "○○○ 진료 녹음을 중단하고 ○○○ 환자 진료 녹음을 시작하시겠습니까?" → 확인 시 기존 세션 종료 및 신규 세션 시작 |

- 조회 중인 환자가 녹음 대상이 아닐 경우, 중앙 녹음 상태바는 **"다른 환자 녹음 중 · ○○○"** 로 표시하며, 선택 시 해당 환자로 이동하고 중지도 가능하다.

### 4.7 대화 패널 (AI 진료 화면 내)
- AI 진료 화면에서도 **대화**를 함께 사용할 수 있다(현재 진료 중인 환자 컨텍스트 기반).
- **넓은 화면 폭**에서는 우측 도킹 패널로 표시하고, **좁은 화면 폭**에서는 우측 하단 플로팅 버튼으로 전환한다.
- 대화 입력창 상단에 **빠른 질문 버튼**(예: "교육 자료 생성", "식이요법 추천")을 제공한다. *버튼 항목은 추후 확정.*

## 5. 대화

### 5.1 응답 방식
사용자가 질문 영역을 구분하거나 지정할 필요 없이 대화창에 질문을 입력하면, 시스템이 질문 성격을 자동으로 판별하여 다음 중 적합한 방식으로 응답한다.
1. **일반 응답** — 의학·업무 질문은 물론 일반·개인적 질문까지 대화형으로 응답한다.
2. **의사랑 데이터 질의** — 질문을 SQL로 변환하여 의사랑 데이터를 조회·추출한 결과로 응답한다(통계·현황 등).

### 5.2 대화 탭 구성
- 상단에 **새 대화** 액션을 제공한다.
- 대화 내역은 **기간별**로 누적·표시한다: **오늘 / 어제 / 지난 7일 / 지난 30일 / 이전**.

## 6. 녹음 상태바 (공통)

대화·AI 진료 탭 상단에 공통 배치하며 두 가지 역할을 수행한다.
1. **AI 진료 빠른 시작** — 선택 시 금일 대기 목록의 환자를 지정하거나 '환자 미지정'으로 녹음을 시작한다.
2. **녹음 상태 표시** — 녹음 중에는 대상 환자명과 경과 시간을 표시한다.

- 녹음 시작 시 해당 진료 화면으로 자동 전환한다(환자 지정 시 해당 환자 진료 화면, 미지정 시 '환자 미지정 녹음' 화면).
- 녹음 중 본 상태바를 선택하면 녹음 중인 환자 진료 화면으로 복귀한다.

## 7. 랜딩(홈) 화면
> 카피(문구)는 미확정이며, 화면 구조만 확정한다.

- 진입 시 **AI 진료**와 **대화** 중 하나를 선택하며, 선택한 기능의 탭이 초기 화면으로 열린다.
- 화면 내에 현재 **의사랑 연동 상태**와 **진료실 실행 상태**를 함께 노출한다.

## 8. 상태 모델 (연동 / 진료실)

| 상태 | 값 | 의미 |
|---|---|---|
| 의사랑 연동 | 연동 / 미연동 | 의사랑 EMR 데이터 접근 가능 여부 |

> 상단바에 위치한 연동/진료실 토글은 실제 제품 기능이 아니라, 프로토타입에서 연동·진료실 실행 상태에 따른 화면 변화를 확인하기 위한 검증용 전환 장치다.

### 8.1 상태별 가용 기능 매트릭스

| 기능 | 미연동 | 연동 + 진료실 미실행 | 연동 + 진료실 실행 |
|---|:---:|:---:|:---:|
| STT 음성기록 / SOAP | ✅ | ✅ | ✅ |
| 대기 환자 목록(대기/예약/완료) | ❌ | ❌ | ✅ |
| 과거 진료기록 요약 | 🔒 | ✅ | ✅ |
| 진단/처방 추천·전송 | 🔒 | 환자 지정 시 ✅ | 환자 지정 시 ✅ |
| 대화 | 🔒 | ✅ | ✅ |

> ✅ 사용 · 🔒 잠금(연동 안내) · ❌ 비노출 — 미연동 상태에서도 '환자 미지정' STT·SOAP는 사용 가능하다.

## 9. 화면 구조 / 반응형
- 데스크톱 앱 형태(타이틀바 포함). 좌측 패널(탭+목록), 중앙(진료/대화), 우측(대화 패널, 넓은 폭 시).
- **대화 패널**: 넓은 폭 → 우측 도킹 패널 / 좁은 폭 → 우측 하단 플로팅 버튼.
- **좌측 패널**: 가변 폭 + 접기/호버 오버레이 + 컴팩트 모드.
